What is Screensaver FX?

A native screensaver for Windows (.scr), macOS (.saver) and Linux (Omarchy, in the terminal): the Omarchy screensaver animations plus 35 new effects. One small Rust core, no web engine, about 5 MB of RAM. The same 41 effects and the same banner typeface on all three systems.

  • 41 effects
  • 11 Omarchy themes
  • Synced multi-monitor
  • ~5 MB RAM
  • Native: .scr, .saver, terminal
  • MIT

Install

Windows 10/11

winget install thealejandro.ScreensaverFX

or grab the installer from Releases.

macOS 11+

brew install --cask thealejandro/tap/screensaver-fx

or open the .dmg from Releases.

Linux (Omarchy)

git clone https://github.com/thealejandro/screensaver-fx
cd screensaver-fx
./linux/install.sh

Requires Omarchy with ttfx; without Rust, the installer downloads the latest release binary.
